## Bunker Tidy Up の進行システムはどう重なっているか

Bunker Tidy Up は、最初の棚でいきなりスキルツリーを渡してくるわけではありません。進行は代わりに重層的です：アイテムを整理し、ゲームが配置を数え、そのカウントが実績を発火させ、それがアンロックシステムへ直接つながっていきます。

コミュニティの実績トラッキングデータが、この曲線を可視化しています。最初の配置はほぼすべての追跡プレイヤーが獲得している一方、最後の整理マイルストーンはおよそ40%付近に位置します。この広がりこそが、進行の弧をそのまま縮図にしたものです。

重要なのは3つの層です：

- **アクション層** — アイテムを正しく配置し、持ち、捨てること。
- **マイルストーン層** — 100、1,000、5,000、10,000回の正確な配置で発火する実績。
- **アンロック層** — アクション層をより速く進めるスキル、アップグレード、コレクティブル。

自分がどの層に取り組んでいるかを把握すれば、「アンロックを無視して配置を延々と周回する」という定番のミスを避けられます。

## 序盤の実績に対応する Bunker Tidy Up のアンロック

序盤は寛容です。ほとんどのプレイヤーは意識せずに最初のマイルストーンを突破します。だからこそ、後半がどれだけ険しくなるかを過小評価しがちです。

| マイルストーン | 追跡プレイヤー完了率 | 何を示すか |
|---|---|---|
| 最初のアイテムを正しく配置する | ~100% | チュートリアル級。誰でも達成 |
| アイテムを100個正しく配置する | ~91.9% | 基本的な整理能力 |
| アイテムを10個以上同時に保持する | ~89.0% | インベントリ管理の始まり |
| 何も捨てずにアイテムを100個配置する | ~80.8% | 速度より正確さが重視される |
| ラックを1つ完全に埋める | ~70.4% | 最初の本格的な整理目標 |
| アイテムを100個捨てる | ~65.1% | 溜め込まず意図的に選別する |

この表には2つの教訓が隠れています。第一に、保持容量は早い段階で重要です——追跡プレイヤーのほぼ90%がただ遊ぶだけでこのマイルストーンに到達しており、このメカニクスが任意ではなく中心的であることを示唆しています。第二に、「捨てない」実績はおよそ81%に位置しており、5人に1人ほどが棚のレイアウトを学ぶ前に反射的に物を捨ててしまっているということです。

## 中盤・終盤のマイルストーン：Bunker Tidy Up のアンロックが本気になる場所

100個から10,000個への落ち込みこそ、カジュアルなプレイが終わり、コンプリート狙いのプレイが始まる地点です。

| マイルストーン | 追跡プレイヤー完了率 | 備考 |
|---|---|---|
| アイテムを1,000個正しく配置する | ~75.6% | 最後の「簡単な」マイルストーン |
| アイテムを5,000個正しく配置する | ~61.1% | 約15ポイントの下落 |
| すべての本を正しく配置する | ~59.9% | 単なる量ではなく独立したサブ目標 |
| アイテムを10,000個正しく配置する | ~45.9% | 追跡プレイヤーの半分以下 |
| すべてのコレクティブルアイテムを集める | ~42.4% | 任意だが完全クリアには必須 |
| すべてのアイテムを正しく配置する | ~40.1% | 量的な上限 |
| すべてのスキルを完全にアンロックしてアップグレードする | ~40.1% | アイテム上限とほぼ完全に一致 |

最後の行が、このデータ全体で最も興味深い部分です。「すべてのアイテムを正しく配置する」と「すべてのスキルを完全にアンロックしてアップグレードする」が同じ完了率に着地しています。コミュニティの報告によれば、これは偶然ではありません——棚を埋め終えることとスキルツリーを完成させることが同時に起きる傾向があり、これはアンロックシステムが別個の作業ではなく、整理した総量に沿ってスケールするよう設計されていることを示唆しています。

要点はこうです：スキルを副次的な活動として扱わないこと。それらは同じメインラインの一部です。

## スキル：Bunker Tidy Up のアンロックを支えるエンジン

スキル進行は、多くのプレイヤーが早い段階で取り組み、遅い段階で放棄する層です。追跡プレイヤーのおよそ91%が少なくとも1つのスキルをアンロックしていますが、すべてを完全にアンロックしてアップグレードしたのは約40%にすぎません。これは51ポイントの差——個々の整理マイルストーンのどの差よりも大きいものです。

| アンロック目標 | 追跡プレイヤー完了率 | 何が分かるか |
|---|---|---|
| スキルを1つアンロックする | ~91.3% | ほぼ全員が序盤に取り組む |
| すべてのスキルを完全にアンロックしてアップグレードする | ~40.1% | 真の長期コミットメント |
| すべてのコレクティブルアイテムを集める | ~42.4% | スキル完全習得よりやや人気が高い |

元データには個々のスキル名やコストが明記されていないため、最も安全なアプローチは行動ベースです：すべてのスキルポイントを、整理スループットの倍率として扱いましょう。より多く運べる、より速く置ける、あるカテゴリをより効率的に整理できる——そうしたアップグレードは、これから先に控える数千回の配置を通じて元を取ります。

長期のプレイに踏み切る前に、**Bunker Tidy Up on Steam** の現在のSteamストアページとパッチ状況を確認しておきましょう。バランス調整によって、優先すべきアップグレードが変わり得るからです。

## より速くアンロックするための段階別プラン

闇雲に周回するのではなく、自分の現在地に優先順位を合わせましょう。

| 段階 | 主な焦点 | 副次的な焦点 | 注意すべき点 |
|---|---|---|---|
| 最初の100回の配置 | 棚のカテゴリを学ぶ | 複数アイテムの保持を練習する | 苛立ちから捨ててしまう |
| 100〜1,000回の配置 | 最初のスキルをアンロックする | ラックを1つ完成させる | アップグレードの通知を無視する |
| 1,000〜5,000回の配置 | スキルアップグレードを積み重ねる | コレクティブルを探して回る | 同じ種類のラックを繰り返す |
| 5,000〜10,000回の配置 | スキルツリーを完成させる | すべての本を片付ける | 長時間プレイによる燃え尽き |
| 最終盤 | 残りのアイテムをすべて配置する | 最後のコレクティブルを集める | 1つの配置ミスを見逃す |

役立つ経験則：スキルツリーに手頃なアップグレードがあるなら、次の長い整理セッションを始める前に取っておきましょう。アップグレードは複利で効きますが、生の配置回数はそうではありません。

## Bunker Tidy Up のアンロックを停滞させるミス

停滞したプレイの多くは、同じいくつかの習慣を共有しています。

| ミス | なぜ悪いか | 対策 |
|---|---|---|
| アイテムをすぐ捨てる | 「捨てずに100個配置」実績を妨げる | 保持して配置する |
| アップグレードせず溜め込む | 多く運べても整理は速くならない | 容量と速度のアップグレードを組み合わせる |
| コレクティブルを飛ばす | 100%クリアを下回る原因になる | 各ゾーンを片付けるたびに探す |
| 本を無視する | 本は独立した追跡マイルストーン | 別パスとして扱う |
| 1つのラックを繰り返し周回する | 総量への進行が遅い | ゾーンをローテーションする |
| アイテム上限付近でやめる | 最後の10%こそ多くのプレイヤーが止まる場所 | 最後の押し込みをセッションに分ける |

6つすべてに共通するパターン：プレイヤーは次の1万回ではなく、次の10分のために最適化してしまっています。

## FAQ

**Bunker Tidy Up のアンロックは全部でいくつありますか？**
実績セットは、スキルのアンロック、スキルツリーの完全完成、コレクティブルの回収に加え、整理量のマイルストーンをカバーしています。実際には、追跡プレイヤーのおよそ40%がアイテム上限とスキル完全アップグレードの両方を達成しており、この2つが密接に結びついていることを示唆しています。

**スキルをアンロックする最速の方法は？**
速くではなく、正確に一貫してアイテムを配置することです。100回と1,000回の序盤マイルストーンでほとんどのスキルポイントが得られるため、落ち着いた正確さは慌ただしい廃棄に常に勝ります。

**コレクティブルは Bunker Tidy Up のアンロックに影響しますか？**
別々に追跡されますが、飛ばすと完全クリアを下回ったままになります。コミュニティデータではコレクティブル完了率は約42%で、スキル完全習得の数値に近いです。

**なぜほとんどのプレイヤーは完了率40%前後で止まるのですか？**
そこは、量のマイルストーン、スキルツリー、コレクティブルがすべて収束する地点です。最終盤は数千回の配置にわたる持続的な正確さを要求し、それは最初の1時間の軽快さとはまったく異なる課題です。

要するに：Bunker Tidy Up のアンロックを3つの別々のチェックリストではなく、1つのシステムとして扱うこと。正確に整理し、余裕があるたびにアップグレードし、進めながらコレクティブルを回収する——そうすれば、40%の壁はもはや壁には見えなくなります。
