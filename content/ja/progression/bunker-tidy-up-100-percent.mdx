## アップグレード優先度：まず容量、速度は後回し

アップグレードはクリア時間を左右する最大のレバーです。序盤のポイントは移動回数を減らすために使いましょう。後半のポイントは探索に費やす時間を減らすために使います。この順序を逆にしたプレイヤーは、同じ通路を2倍の頻度で歩くことになります。

運搬容量と手持ちストレージは最初の1時間で最も重要です。棚への往復はすべて純粋なオーバーヘッドだからです。1カテゴリを1〜2回の運搬で移動できるようになれば、Magnetismとアイテム探索ツールはすぐに元を取れます。

| アップグレード | 優先度 | 買うべきタイミング | 実際に節約できるもの |
| --- | --- | --- | --- |
| 拾得／運搬容量 | 最高 | 最初の数ポイント | 棚への数十回の往復 |
| スタック処理 | 高 | 序盤〜中盤 | 同一アイテムを入れ替える時間 |
| 移動速度 | 中 | 序盤または中盤 | フロア間の長い移動 |
| Magnetism | 高 | 中盤 | 散らばった群れを手作業で拾う時間 |
| アイテムファインダー | 高 | 中盤〜終盤 | 希少な個体を闇雲に探す何時間もの時間 |
| アルティメット収納 | 中〜高 | 終盤 | 混在したインベントリの仕分け時間 |

### 序盤に買わなくていいもの

最初のポイントをジャンプの高さや見た目だけの移動パークに注ぎ込まないでください。速い移動は、ほぼ空のインベントリで棚までよろよろ戻ることを補えませんし、垂直方向の機動力が本当のボトルネック——アイテムの識別——を解決することはほとんどありません。そうした快適性の購入は、容量、Magnetism、ファインダーが揃ってからに取っておきましょう。

コミュニティの報告では、1つのアビリティだけを他を犠牲にして過剰にアップグレードすることも警告されています。バランスの取れたキット——中程度の容量、機能するMagnetism、使えるファインダー、信頼できるアルティメット——は、1つのステータスをカンストさせたものよりほぼ常に優れています。

## 繰り返し使える仕分けルート、手順ごとに

1. **手ぶらで1周する。** 何も持たずに両方のフロアを歩き、主要ゾーンがどこにあるかメモします：飲み物、食料品、スナック、スパイスとソース、缶詰、ペットフード、日用品、サバイバル装備、薬、本、武器。
2. **大きなオブジェクトから片付ける。** 給水樽、燃料キャニスター、バックパック、発電機、消火器、箱は見間違えようのないシルエットです。序盤の経験値を稼ぎ、床のスペースを空けられます。
3. **2カテゴリのルートを組む。** 棚が近いアイテム種を組み合わせて、1回の移動で1つではなく2つのニーズを満たしましょう。
4. **こまめに収納するが、神経質になりすぎない。** 3個拾うたびに戻るのではなく、自然な区切りで満杯のインベントリを空にしましょう。
5. **アビリティは残り物ではなく群れに使う。** Magnetismとアルティメット収納は、最後の2個よりも、20個の同種アイテムが密集した群れに対して使う方がはるかに価値があります。
6. **精密モードに切り替える。** カテゴリがほぼ完了したら、記憶に頼らず、そのアイテムを1つ手に持ってファインダーに導いてもらいましょう。

| アイテム群 | 役立つ視覚的手がかり | 取り扱いのメモ |
| --- | --- | --- |
| 飲み物 | ボトル、缶、カートン | 棚が近ければ水関連製品とまとめる |
| 缶詰 | 均一な金属製の円筒 | 山の中では見つけやすいが、単体では見落としやすい |
| ペットフード | 袋と缶 | 犬用と猫用は分けておく |
| 本 | 平たい長方形と見える背表紙 | 中盤の移動に適した埋め合わせアイテム |
| 医療品 | 白いキット、包帯、ブリスターパック | ファインダー能力が輝く分野 |
| 日用品 | 洗剤ボトル、箱、チューブ | 上の棚と角を注意深く確認する |
| サバイバル装備 | バックパック、消火器、工具 | シルエットが分かりやすい序盤に片付ける |

## 終盤の片付け：最後の隠れたアイテムを追う

最後のひと山こそ、多くのBunker Tidy Up 100%挑戦が足踏みする場所です。大きなカテゴリは終わり、残っているのは何百もの似た小さなオブジェクト——缶、瓶、電池、マッチ、歯磨き粉、食品パック——で、床や棚に視覚的に溶け込んでいます。

解決策はスピードではなく規律です。残数が管理できるカテゴリを選び、完全に終わらせてから次へ進みます。アイテム種を絶えず切り替えると、どこを確認済みか覚えられなくなり、同じ場所を何度も探すことになります。

| 終盤の問題 | 実践的な解決策 |
| --- | --- |
| 小さなアイテムが視覚的に消える | 名前ではなく形、色、棚カテゴリで探す |
| あと1〜2個だけ残っている | 一致するアイテムを手に持ち、ファインダーを作動させる |
| インベントリがすぐ満杯になる | よりこまめに収納し、手持ち容量を上げる |
| アビリティが無駄に感じる | 残った個体が密集した群れのために取っておく |
| アイテムがどこにも置けない | 推測する前にカテゴリ表示を確認する |
| 進行が止まって見える | 下のフロアと以前クリアしたルートを再確認する |

### 最終コンプリートのチェックリスト

- バンカーの両フロアと、到達できるすべての角を歩く
- 残数の少ないカテゴリはアビリティではなく手作業で終わらせる
- Magnetismは大きな繰り返し群にのみ使う
- ファインダーを作動させる時は常にアイテムを1つ手に持つ
- アルティメット収納は満杯か混在した積載量に対して使う
- どの棚カテゴリにも未完了の山がないことを確認する

最後の10%には、それ専用の計画が必要です。中盤を支えてくれたアビリティは終盤ではしばしば無駄になるので、速度を落とし、几帳面にスキャンし、残った各カテゴリを小さく自己完結した仕事として扱いましょう。

## FAQ

**Bunker Tidy Upの100%コンプリートにはどれくらいかかりますか？**
ほとんどのプレイヤーは数時間を見積もるべきです。広く共有されているプレイスルーの一例では約4時間半でゴールに到達していますが、時間はアップグレードの選択、棚のレイアウトを覚える速さ、そして最終片付けをどれだけ几帳面に進めるかに大きく左右されます。

**最初に買うべきアップグレードはどれですか？**
運搬容量です。すべての移動の生産性を上げるため、序盤で最も安全な投資です。次にスタック処理、続いてMagnetism、その後アイテム探索、そしてインベントリが常に満杯になるようになったら最後にアルティメット収納です。

**1カテゴリずつ仕分ける方が良いですか？**
終盤では間違いなくそうです。カテゴリに集中した仕分けは残数を追いやすくし、すでにクリアした部屋を探し直すのを防ぎます。序盤はもっと緩くても問題なく、近くにある大きなオブジェクトを手当たり次第に拾ってかまいません。

**残りアイテムがわずかになったらどうすべきですか？**
見つからないアイテムを1つ手に持ち、ファインダー能力があれば使いましょう。なければ、バンカーを手作業で慎重に——角、大きなオブジェクトの下の空間、下のフロアの端、何十回も横を通り過ぎてよく見なかった棚を——確認します。
