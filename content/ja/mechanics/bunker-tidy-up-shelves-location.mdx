1つの棚を見失うと、それを探すより多くの時間を失う。Bunker Tidy Upでは、保管室はどれも似て見え、ラックは壁に沿って繰り返し並び、10分前に片付けた棚も、戻ってくる頃には手つかずのように見える。それぞれの **Bunker Tidy Upの棚の場所** が正確にどこにあり、どんな状態かを把握することが、着実な前進と終わりのない再確認ループの分かれ目になる。

このガイドでは、すべての **Bunker Tidy Upの棚の場所** を自分が管理する記録として扱う。エリアにラベルを付け、一方向に見て回り、状態をすぐ記録し、次へ進む前に確認する。その習慣が、大規模な回収目標を圧倒されるものではなく、管理可能なものにする。

## 各棚の場所で記録すべきこと

Bunker Tidy Upで最もよくある失敗は、棚を逃すことではない。すでに処理した棚を忘れることだ。記憶は部屋から部屋への移動に耐えられず、よく似た2つの廊下は1つに混ざってしまう。

すべての保管エリアについて3つ記録する：どこにあるか、どのカテゴリのアイテムを置くか、完全に確認済みか。空に見える棚でも、より大きな保管セクションの一部かもしれない。一方、部分的に整理された棚は、終わった部屋を未完了に見せる。

| 項目 | 記録する内容 | 役立つ理由 |
| --- | --- | --- |
| エリア名 | 部屋、廊下、角、保管ゾーン | 重複検索を防ぐ |
| 棚の識別子 | 左、中央、右、上段、下段 | 数センチしか離れていない棚を区別する |
| アイテムグループ | バッテリーまたは他の見えるカテゴリ | 部屋をまたいで整理を一貫させる |
| ステータス | 未確認、進行中、整理済み、確認済み、保留 | 次の作業を一目で示す |
| メモ | 見つからないアイテム、遮られた視界、再訪理由 | 後のセッションに手がかりを残す |

**Room A - Shelf 01** や **Storage West - Upper Rack** のような固定の命名パターンを使う。正確な言葉は一貫性ほど重要ではない。複数のゾーンが同じ配置を共有するとき、安定したラベルだけがそれらを見分ける確実な方法だ。

### 部屋の見回り、棚チェック、確認パス

- **部屋の見回り：** 入室し、片方の壁に沿って進み、方向を変える前に見える棚の列を終える。
- **棚チェック：** 各棚を上から下へ確認し、その場ですぐ記録する。
- **確認パス：** バンカー全体をやり直すのではなく、フラグを付けた棚だけを再訪する。

コミュニティの報告では、プレイヤーが飛ばしがちな手順こそ確認パスであり、それが二重カウントを最も多く生むことが一貫して示されている。

## ルート計画：重複せずにすべての場所を回る方法

ルートは、棚の場所に関する最もよくあるミスを解決する。同じ角を3回確認する一方で、セクション全体が手つかずになることだ。以下の手順は特定の部屋配置に依存しないため、マップ知識が増えても機能し続ける。

1. **目印を選ぶ。** 正面入口、広い戸口、特徴的な設備を使う。その目印が、ルートをリセットする場所になる。
2. **先に片側を片付ける。** 左または右の壁に沿い、部屋を横切る前に見えるすべての棚を確認する。行き来すると隙間ができる。
3. **確認方向を1つに保つ。** 各棚を上から下、または下から上へ読むが、途中で切り替えない。確認後すぐに棚を記録する。
4. **不確かなものにフラグを付ける。** 物体や角度が確実な確認を妨げるなら、その棚を保留にする。保留は空と断定するより常に安全だ。
5. **ループを閉じる。** 開始地点の目印に戻り、次へ進む前に部屋を記録と照合する。

| ルート段階 | やること | 完了の合図 |
| --- | --- | --- |
| 開始 | 目印を選び、ゾーンにラベルを付ける | 開始地点が記録される |
| 最初のパス | 片方の壁または通路に沿う | 見えるすべての棚にステータスがある |
| 詳細チェック | 上段、中段、下段を確認する | どの棚セグメントも飛ばしていない |
| 例外パス | 遮られた棚や不確かな棚を再訪する | 保留項目が解決する |
| 退出チェック | 部屋を記録と照合する | ルートが目印に戻る |

部屋に近接した棚が複数ある場合は、より小さなゾーンに分割する。**北壁**、**中央ラック**、**ドア側の棚** のようなラベルは、「保管室」のような1つの広いラベルより、見つからないアイテムをはるかに早く特定する。

### 誤った完了を避ける

前列がきれいに見えるだけで棚を完了にしてはいけない。隠れた部分、高い部分、遮られた部分は、自信を持って確認できるまで保留のままにする。Bunker Tidy Upに関するコミュニティ報告ではこれが繰り返し言及されている。整った前列は、その背後にある未完了の層全体を隠しうる。

## バッテリーと棚グループの整理優先度

最良の整理システムは、考えずに繰り返せるものだ。見えて置きやすいアイテムから始め、残った棚スペースを使って、まだ足りないものを露出させる。部屋間でアイテムをランダムに動かすと、記録が読めなくなる。

バッテリー目標には、3段階の優先度がうまく機能する：

1. 進行中ゾーンで見えるバッテリーをすべて回収する。
2. 正しい棚グループ、または明確にラベル付けした作業用の山に置く。
3. 配置後に棚を確認し、同じエリアを二重カウントしない。

| 優先度 | タスク | 推奨アクション |
| --- | --- | --- |
| 高 | 進行中ゾーンの見えるバッテリー | すぐ回収して記録する |
| 高 | ステータスが不確かな棚 | 保留にして、離れる前に確認する |
| 中 | 部分的に整理された棚 | 広げる前にそのセクションを終える |
| 中 | 近くの散らばったアイテム | 見える種類や棚の用途でグループ化する |
| 低 | 以前に確認済みの棚 | 数が合わない場合のみ再訪する |

Bunker Tidy Upの参考資料やコミュニティ資料では、見つけて整理すべきバッテリー420個という目標が説明されている。だからこそ、1つの巨大な合計よりエリア単位のマイルストーンが勝る。バンカーごとではなく、部屋ごとに数える。

| コード | 意味 | 次のアクション |
| --- | --- | --- |
| U | 未確認 | 次のルートパスで確認する |
| A | 進行中 | 現在検索または整理中 |
| S | 整理済み | アイテムを配置し、セクションが見た目上整理されている |
| V | 確認済み | 整理後に再確認済み |
| P | 保留 | アクセスまたは視界が遮られ、再訪が必要 |

**整理済み** と **確認済み** の差は、記録における他のどんな区別よりも重要だ。整理済みとは、現在のパスの後で棚が整理されて見えることを意味する。確認済みとは、戻ってきて、見えるものが見落とされていないことを確認したという意味だ。棚を確認済みに昇格させるのは、部屋のルート全体を終えた後だけにする。

## 棚の場所チェックリストと進捗レビュー

毎セッションの開始時にこのチェックリストを実行する。1分未満で終わり、きれいなバンカーを紛らわしいものに変えるゆっくりしたずれを防ぐ。

- 目印を選び、現在のエリアに名前を付ける
- 一貫した1つの方向で棚を確認する
- すべての棚にステータスを付ける：未確認、進行中、整理済み、確認済み、保留
- 終わった部屋と進行中の部屋を分けておく
- 広い新しい見回りを始める前に保留の棚を片付ける

| レビュー質問 | 合格条件 | そうでない場合 |
| --- | --- | --- |
| 見えるすべての棚にラベルが付いたか？ | 名前のない棚が残っていない | 離れる前にラベルを追加する |
| ルートは開始地点に戻ったか？ | 部屋全体のループが完了 | 見逃した側を繰り返す |
| 不確かなエリアにフラグを付けたか？ | 保留の棚が一覧にある | 続ける前にマークする |
| アイテムグループは記録されたか？ | バッテリーまたは他のアイテムが特定されている | カテゴリメモを追加する |
| 部屋は確認済みか？ | 2回目の確認パスが完了 | 整理済みのままにする |

役立つ進捗記録は、4つの問いに即答する：どのエリアが終わったか、どの棚が保留か、このセッションで何個のアイテムが移動したか、次のルートはどこから始めるべきか。

### 数が合わないときのトラブルシューティング

合計が期待と合わない場合でも、バンカー全体をやり直したくなるところをこらえる。記録から、保留項目、重複した棚ラベル、整理済みだが一度も確認していない部屋をチェックする。この3カテゴリに不一致が含まれることがほとんどで、完全な再検索よりはるかに速く監査できる。

棚を早すぎる段階で確認済みに昇格させることが、プレイヤーがすでに片付けた部屋を再び歩く最大の理由だ。確認済みの棚は推測ではなく約束であるべきだ。

## FAQ：Bunker Tidy Up 棚の場所

**Q: Bunker Tidy Upでは何個のバッテリーを整理する必要がありますか？**
ゲームの参考資料やコミュニティ資料では、見つけて整理するバッテリー420個という目標が説明されている。その数字は、1つの累計に頼るのではなく、エリア単位の記録を付ける理由だと考えよう。

**Q: すべてのBunker Tidy Upの棚の場所を追跡する最速の方法は？**
各棚に部屋と位置に紐づいた短いラベルを付け、確認し終えた瞬間にステータス（未確認、進行中、整理済み、確認済み、保留）を記録する。後から記録するのが、正確さが崩れるところだ。

**Q: 整理を始める前にバンカー全体を検索すべきですか？**
いいえ。一度に定義した1つのエリアだけを進める。見回し、整理し、確認し、それから次へ移る。部屋ごとのアプローチなら、未完了の棚が散らかったアイテムの山の背後に埋もれず、見える状態に保たれる。

**Q: 棚が不完全に見えるときはどうすればいいですか？**
完了ではなく保留にし、部屋のルートが終わったら再訪する。物体やカメラアングルで視界が遮られたなら、その棚はカウントする前に再確認する価値がある。

**Q: 整理後に本当に棚を確認する必要がありますか？**
はい。確認は、確かな進捗と希望的観測の進捗を分けるものだ。それがなければ、大規模な回収目標は当て推量になり、すでに片付けた部屋を再び歩くことになる。

きれいなバンカーの核心は単純だ。1つの目印、1つの方向、棚ごとに1つのステータス。命名パターンを選び、触れたすべての棚を記録し、祝う前に確認する。そうすれば、すべてのBunker Tidy Upの棚の場所は疑いの種ではなく、信頼できる1つの項目になる。
