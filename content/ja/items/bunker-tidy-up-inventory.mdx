## 手に負える Bunker Tidy Up Inventory のための基本仕分けルール

Bunker Tidy Up のすべては、たった一つの原則に集約されます。棚は、カテゴリが一致したときだけアイテムを受け入れるのです。間違って置けば赤く点滅し、棚の進行度にカウントされず、移動させるまで静かに完成を妨げ続けます。この赤い点滅を小さな煩わしさではなく警告サインとして受け止められるかどうかが、着実な前進と何時間もの後戻りの分かれ目になります。

| 仕分けの原則 | なぜ重要か | やるべきこと |
| --- | --- | --- |
| まず正しいカテゴリ | 置き間違えたアイテムは棚の進行度にカウントされない | 手を空ける前に棚のラベルを読む |
| かさばる物資を先に | 大きな物資は床の面積を奪い、小さな物を隠す | 発電機、水容器、防具を先に片付ける |
| 同じアイテムをまとめる | 重複品は往復回数を減らす | 一度に 1 種類のアイテムだけを運ぶ |
| 目に見える山を片付ける | 埋もれた物資は見落としやすい | 深く探す前に表面の散らかりを取り除く |
| 縦方向に掃討する | アイテムは上階、下階、家具の脇に出現する | 階を変える前に 1 フロアを終わらせる |

### かさばる物資から始める

水容器、発電機、ボディアーマー、バックパック、燃料キャニスターは、このゲームで最も簡単な得点源です。どれも大きく、見分けやすく、たいていは開けた場所にまとまっているので、片付ければ部屋全体の見通しがよくなります。それらが消えれば、残った散らかりはずっと読み取りやすくなります。

### 運搬上限を守る

開始時の運搬容量はわざと小さく設定されています。ランダムな物を手に詰め込めば、正しい棚に着いたときには間違ったものを持っていることになります。狙うカテゴリを 1 つ決め、見つけた該当アイテムをすべて集め、1 回の目的ある移動で運びましょう。長期プレイヤーは、序盤は移動速度よりもルート計画のほうが重要だと口を揃えて言います。

## Bunker Tidy Up Inventory の往復を速くするアップグレード順

アップグレードは、物資を集める、見分ける、置くという一連の速さを決めます。序盤に最も強い買い物は、便利さを足すものではなく、探す時間と歩く時間を削るものです。Magnet と Match Finder がその筆頭に挙げられるのは、どちらも bunker tidy up inventory にまだ必要なアイテムを探し回る時間を直接短縮してくれるからです。

| アップグレード | 主な機能 | 最適な使用場面 |
| --- | --- | --- |
| Magnet | 近くの同種アイテムを手元に引き寄せる | 広い部屋に散らばったよくある物資を片付けるとき |
| Match Finder | 同じ種類の他のアイテムをハイライト表示する | 隠れた、あるいは遠くの重複品を見つけるとき |
| Carry Capacity | 保持できるアイテム数を増やす | 往復回数を減らしたいとき |
| Quick Step | 移動速度を上げる | 多層構造のフロアを効率よく移動するとき |
| Right Shelf | 手に持ったアイテムの置き場所を示す | カテゴリの判断に迷ったとき |
| Auto Loader | ボタンを押している間にアイテムを置く／取り出す | 繰り返す棚の操作を速くしたいとき |
| Scatter | 持っているアイテムを既に同種が入った棚へ送る | 同一アイテムの大きな山を片付けるとき |

シンプルな判断プロセスで、アップグレードポイントを無駄にしないようにしましょう。

1. 自分のボトルネックを特定する。探すこと、運ぶこと、歩くこと、置くことのどれか？
2. どのカテゴリを完成させるか分かり、近くに複数の同種アイテムが見えたら Magnet を買う。
3. 最初のアイテムを拾った直後に Match Finder を追加し、ハイライトが消える前に覚えておく。
4. ルートを終える前に手が埋まるようになって初めて Carry Capacity に投資する。

強そうに見えるというだけで、長いクールダウンを持つ能力を買うのは避けましょう。アップグレードが現在のボトルネックを減らさないなら、ポイントは温存です。

## よりきれいな Bunker Tidy Up Inventory のためのルート計画

信頼できる掃討パターンは、どんなときも生の移動速度に勝ります。バンカーは複数の階にわたり、物資はソファの脇、手すりの裏、せり上がった平台の上に隠れています。同じルートを同じ順序で回れば、何かを見落としたときにすぐ気づけます。

| ルート段階 | 対象の物資 | 方法 |
| --- | --- | --- |
| フェーズ 1 | 水容器、発電機 | 開けた上層・下層エリアを掃討する |
| フェーズ 2 | 防具、バックパック、燃料 | 床が空いた状態で同じ経路を繰り返す |
| フェーズ 3 | 武器と防護装備 | 角、家具の縁、平台を確認する |
| フェーズ 4 | 医薬品と清掃用品 | 片付いた区域で小さなアイテムを探す |
| フェーズ 5 | 食料、本、日用品 | マッチング能力を使ってカテゴリごとに仕上げる |

| 探索の問題 | 考えられる原因 | 対処法 |
| --- | --- | --- |
| まだ 1 つ足りない | 散らかりの下や家具の裏に埋もれている | 近くの山を片付け、床の縁を確認する |
| 棚が 90% で止まる | 間違ったカテゴリの棚にアイテムがある | ラベルを読んで置き間違えを移動させる |
| 部屋が空に見える | 小さなアイテムが背景に溶け込んでいる | Match Finder を発動するか、きれいな山を調べる |
| ルートが果てしなく感じる | 1 回の移動でカテゴリを切り替えすぎている | 次へ移る前に 1 つのグループを終わらせる |

Match Finder が発動したら、少しだけ立ち止まりましょう。ハイライトが消える前に部屋全体をスキャンすれば、何度もの無駄な往復を防げます。見えているアイテムに手が届かないように思えたら、同じ経路で格闘するのではなく別の角度から近づきましょう——このバンカーの家具は、見た目以上に移動を阻みます。

## Bunker Tidy Up Inventory の流れを乱す厄介なカテゴリ

分かりやすい棚もあれば、もう一度よく見る必要がある棚もあります。最も厄介なのは食料で、飲み物、食料品、缶詰の野菜、缶詰の肉と魚、保存食品、菓子とスナック、香辛料とソース、動物用フードという別々の棚に分かれています。似たパッケージだからといって、同じカテゴリとは限りません。

| アイテム群 | よくある例 | 仕分けの注意点 |
| --- | --- | --- |
| サバイバル装備 | 水容器、発電機、バックパック | 早い段階で目に見え、片付けも速い |
| 武器と防護 | ショットガン、斧、バット、防具、ガスマスク | 道具と医療品は分けておく |
| 日用品 | トイレットペーパー、歯磨き粉、清掃用品 | 似て見えるアイテムはラベルを確認する |
| 食料と飲み物 | ソーダ、水、シリアル、缶詰、瓶詰 | 正確な食料サブカテゴリを使う |
| 動物用フード | キャットフード、ドッグフード | 専用のペット棚にだけ置く |
| 本 | 農業、治療、サバイバル、狩猟 | 手を空ける前に棚の説明を読む |

### 本はそれ自体がパズル

本は治療、サバイバル、農業、狩猟、技術、修理、バンカー生活を扱っています。棚のラベルを覚えるまでは、汎用の「知識」棚があると決めつけず、1 冊ずつ仕分けの問いとして扱いましょう。

### 小さな物を忘れない

清掃用品やトイレタリーは、発電機や武器に比べて小さいため見落としがちです。大きな物がなくなったら、たまたま見つけたときに拾うのではなく、日用品専用の掃討を行いましょう。アイテムが赤くなったら無理押しせず、一度持ち上げ、隣のラベルを読み、可能な中で最も具体的なカテゴリを試しましょう。

## ラストスパート：Bunker Tidy Up Inventory の最後のアイテム

終盤はいつも遅く感じられます。残っているのは小さなもの、隠れたもの、家具の裏にあるもので、まさに精度が最も求められる場面でモチベーションが下がりがちです。完成した棚を見た目の目印にして、まだ物が残っている区域だけを探しましょう。

| 終盤のタスク | 優先度 | 理由 |
| --- | --- | --- |
| ほぼ完成した棚を仕上げる | 高 | 素早い進展には少しの探索で済む |
| よくあるカテゴリに Magnet を使う | 高 | 一致する多くのアイテムを一度に片付ける |
| 家具の裏を確認する | 高 | 隠れた物資がしばしば残っている |
| 赤い配置を再確認する | 中 | 置き間違えは棚の完成を妨げる |
| 孤立した小さな物を探す | 中 | 大きな散らかりが消えてからが最適 |

うまく機能する仕上げのチェックリスト：

- 目に見える水容器と発電機をすべて仕分ける
- 防具、バックパック、燃料のカテゴリを完成させる
- 残った武器と防護装備を片付ける
- 食料、飲み物、医薬品、動物用フードを分ける
- 終わりと決める前に、埋もれた物と家具の縁を調べる

カテゴリを完成させるとアップグレードポイントが手に入ることが多いので、頑固な 1 つのアイテムに固執するより、小さな棚をいくつか仕上げるほうが賢いこともあります。

## よくある質問

**bunker tidy up inventory を整理する最速の方法は？**

水容器、発電機、防具、バックパック、燃料など、大きくて見つけやすい物資から始めましょう。その後は Magnet と Match Finder に頼りながら、一度に 1 つのカテゴリを仕上げて探索を減らします。

**最初に買うべきアップグレードは？**

Magnet と Match Finder が序盤最強の選択です。回収と発見の両方を改善してくれるからです。Carry Capacity と Quick Step は、ルートが長くなり手が早く埋まるようになってから価値が増します。

**棚でアイテムが赤くなるのはなぜ？**

赤いアイテムは間違ったカテゴリの棚にあり、完成にカウントされません。取り除き、近くのラベルを読み、最も具体的に一致するカテゴリへ置きましょう。

**Bunker Tidy Up で最後の 1 つの物資はどう見つける？**

周囲の散らかりを片付け、家具の裏や目に見える山の下を確認し、いつもと同じルートで各フロアを掃討しましょう。Match Finder は、ある種類のアイテムが完成まであと 1 つというときに最も役立ちます。

最も信頼できるのは、急ぐことではなく整然と進めることです。大きなアイテムを片付け、回収ツールを強化し、カテゴリを集中してまとめて仕上げ、最後の掃討は隅に隠れているもののために取っておきましょう。
