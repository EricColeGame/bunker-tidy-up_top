### 大きな物資から始める

まず給水容器、発電機、防弾チョッキ、バックパック、燃料キャニスターに集中します。これらのアイテムは目につきやすく、必要な配置回数も少なめで、床スペースをすぐに広げられます。大きな物がなくなれば、小さな物資も見分けて仕分けやすくなります。

### 同じアイテムをグループ化する

同じ物資をまとめると往復が減ります。農業に関する本を1冊見つけたら、棚に戻る前に他の農業本を探しましょう。缶詰、掃除用品、医療品にも同じことが言えます。種類ごとにまとめることで、散らばった掃除が集中した回収作業に変わります。

## Bunker Tidy Up 最速掃除のための最適なアップグレード順

アップグレードは、物資を集め、識別し、配置する速さを決めます。最も強力な序盤の改善は、ちょっとした便利さを足すものではなく、歩行と探索を減らすものです。コミュニティの報告では、最初の大きなQoL解放として Magnet と Match Finder が一貫して挙げられています。

| アップグレード | 主な機能 | 最適な使い方 |
| --- | --- | --- |
| Magnet | 近くにある同じ種類のアイテムを手元に引き寄せる | 開けた部屋でよくある物資を集める |
| Match Finder | 持っているアイテムの他の複製をマークする | 隠れた、または遠くの同種アイテムを見つける |
| Carry Capacity | 運べるアイテム数を増やす | 往復回数を減らす |
| Quick Step | 歩行速度を上げる | バンカーをより効率的に移動する |
| Right Shelf | 手持ちアイテムの正しい棚を表示する | 不確かなカテゴリを解決する |
| Auto Loader | ボタンを押し続ける棚への繰り返し操作を自動化する | 棚への配置を繰り返す |
| Scatter | 手持ちアイテムを、すでに一致する物資がある棚へ送る | 同じオブジェクトの大きなまとまりを片付ける |

Magnet は、ある物資タイプが複数の見える場所にあるときに強力です。Match Finder は、1つのアイテムを拾った後、ハイライトが消える前に他の複製を表示するのに役立ちます。プレイヤー体験では、すぐに移動するのではなく、その場所を覚えるために少し止まることが推奨されています。

### 序盤の最適なアップグレード順

1. ボトルネックを特定する。問題は探索、運搬、歩行、配置のどれか？ その問題を正確に解決するアップグレードを買いましょう。
2. Magnet を解放する。どのカテゴリを完了するかすでに分かっていて、一致するアイテムが複数見えるときに使いましょう。
3. Match Finder を追加する。1つアイテムを拾い、部屋をスキャンしてハイライトを確認し、位置を覚えます。
4. 運搬容量を増やす。ルートを完了する前に手が埋まるようになったらアップグレードしましょう。

現在のボトルネックを解決しない、長いクールダウン付きの能力にポイントを使うのは避けましょう。Bunker Tidy Up 最速掃除では、効率はすべての派手なアップグレードを買うことではなく、無駄な往復を減らすことから生まれます。

### 移動アップグレードを買うタイミング

Quick Step は、バンカーのレイアウトに慣れてからより役立ちます。移動速度は、フロア間を何度も行き来するときに重要です。Jump が役立つ場面もありますが、仕分け効率を直接改善するアップグレードの代わりにはなりません。まだ迷うなら、速く歩くことよりもルート計画のほうが役立ちます。

## 各フロアの効率的なルートと探索パターン

効率的なルートは、生の移動速度に勝ります。バンカーには複数階、家具の横、散らかりの下に物資があります。一貫した探索パターンが、繰り返しの探し物を防ぎます。まず大きすぎるオブジェクトを探しましょう。見つけやすく、視界を広げてくれるからです。

| ルート段階 | 対象物資 | ルート方法 |
| --- | --- | --- |
| フェーズ1 | 給水容器と発電機 | 上と下の見えるエリアを両方確認する |
| フェーズ2 | 防具、バックパック、燃料 | 床がきれいな間に同じ経路を繰り返す |
| フェーズ3 | 武器と防護用品 | 角、家具の端、高い台を調べる |
| フェーズ4 | 薬と掃除用品 | 片付いたエリアをよく見て小さなアイテムを探す |
| フェーズ5 | 食べ物、本、家庭用品 | 各カテゴリを終わらせ、対応する能力を使う |

信頼できるループはこうです。下の階、上の階、家具の端、そして隠れた角。同じパターンを繰り返すことで、見落とした物資が目立つようになります。アイテムが見えるのに取りにくい場合は、同じ動きを無理に続けず、別の角度から近づきましょう。

### 繰り返せる探索ループ

フロアを片付けるたびに同じ経路を使いましょう。一貫性が目を鍛えます。2、3回ループすると、隙間や隠れたオブジェクトに早く気づけるようになります。これは、すべてのアイテム位置を覚えなくても Bunker Tidy Up 最速掃除を達成する最も簡単な方法の1つです。

### 家具と垂直移動

ソファ、手すり、棚、高い台は直接の道をふさぐことがあります。アイテムが見えるのに届きにくい場合は、一歩下がって別の角度から近づきましょう。階を変える前に、1つのエリアを完全に終わらせます。早すぎる階移動は、同じ部屋を2回探す原因になりがちです。

| 探索の問題 | 考えられる原因 | 解決策 |
| --- | --- | --- |
| 1つのアイテムだけまだ見つからない | 埋もれているか、家具の後ろに隠れている可能性 | 近くの散らかりを除去し、床の端を調べる |
| 棚が完成しない | アイテムが間違ったカテゴリの棚にある可能性 | ラベルを読み、間違って置かれた物資を移動する |
| 部屋が空っぽに見える | 小さなアイテムが背景に溶け込んでいる | Match Finder を使うか、片付けた山を確認する |
| ルートが長すぎると感じる | カテゴリの切り替えが多すぎる | 切り替える前に1つのアイテムグループを終える |

このルート規律が Bunker Tidy Up 最速掃除の核心です。より速く動いているのではなく、より少ない判断で動いているのです。

## 紛らわしい物資のカテゴリガイド

明らかなカテゴリもあれば、よく読む必要があるものもあります。特に食べ物は幅広く、飲み物、食料品、缶詰野菜、缶詰の肉と魚、保存食品、菓子とスナック、スパイスとソース、動物の餌で棚が分かれています。アイテムの機能と見た目を出発点にしますが、置く前に棚のラベルを確認しましょう。

### 食べ物と動物の餌

飲み物は食料品と分けたままにします。ペットフードは一般の食料品と混ぜないでください。2つのアイテムが似て見えるときは、推測せずに棚のラベルを読みましょう。素早いラベル確認が赤い配置を防ぎ、往復を節約します。

### 本と掃除用品

本は、そのテーマがサバイバル、治療、農業、狩猟、技術、修理、バンカー生活と重なるため、見た目以上に難しいことがあります。正しいラベルに慣れるまで、各本を独自の仕分けパズルとして扱いましょう。掃除用品も、発電機や武器より小さいため見落としがちです。大きな物がなくなったら、家庭用品専用の探索を行いましょう。

- アイテムが赤くなったら、その棚に無理に置き続けない。
- もう一度拾い、近くのラベルを読み、最も具体的なカテゴリを試す。
- 似たアイテムが別のサブカテゴリに属していないか確認する。
- 手持ちアイテムがどこに属するか分からないときは Right Shelf を使う。

## 終盤戦略: 最後の見つからないアイテムを見つける

最終段階は、残った物資が通常より小さく、目立たず、散らかりの下に隠れているため遅くなります。ルートを放棄しないでください。完成した棚を視覚的な目印にし、まだバラのアイテムがあるエリアだけを探します。仕上げのルーティンは簡単です。各フロアを時計回りに調べ、家具の後ろを確認し、クールダウンが明けたら能力を使いましょう。

| 終盤のタスク | 優先度 | 理由 |
| --- | --- | --- |
| ほぼ完成した棚を完成させる | 高 | 探す回数が少なく、進行が早い |
| よくあるカテゴリに Magnet を使う | 高 | 一致する多くのアイテムを一度に片付ける |
| 家具の後ろを確認する | 高 | 隠れた物資がそこに残りがち |
| 赤い配置を再確認する | 中 | 間違ったアイテムが棚の完成を妨げることがある |
| 孤立した小さなオブジェクトを探す | 中 | 大きな散らかりがなくなった後まで取っておくのが最善 |

### ほぼ完成した棚を先に終わらせる

棚にあと1、2個しか必要ないなら、バンカー中をランダムなオブジェクトを追う前にそれを完成させましょう。カテゴリを完了するとアップグレードポイントが得られ、そのポイントで残りの片付けを速くできます。小さな勝利はすぐに積み重なります。

カテゴリを完了するとアップグレードポイントが得られるため、難しい1つのオブジェクトを探すより、小さなグループを終わらせるほうが効率的な場合があります。Bunker Tidy Up 最速掃除では、終盤は必死な探索ではなく、計画を持った忍耐が大切です。
