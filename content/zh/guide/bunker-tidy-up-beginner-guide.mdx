散落的电池、整理到一半的架子，以及完全不记得自己已经清理过哪个角落——大多数人的第一次游戏就是这样结束的。一份可靠的 **Bunker Tidy Up 新手指南** 会用一套可重复的短循环取代手忙脚乱的抓取。这份 Bunker Tidy Up 新手指南涵盖扫描-分类-复查的节奏、一条你真正能记住的路线，以及一套防止你重复清理同一层架子的进度系统。

整理地堡不是一场速度竞赛。公开分享的游戏细节指出，420 块电池是一个主要的收集目标，这意味着最先完成的玩家往往是那些沉着行动而非追求速度的人。以下是新玩家从第一次游戏开始就需要养成的习惯。

## 核心循环：扫描、分类、复查

无论你是清理一层架子还是一整个储藏室，每次整理都遵循同样的三个节拍。

- **扫描：** 在触碰任何东西之前，先确认眼前实际有什么。散落的电池、空置的架子槽位，以及明显属于别处的物品，是你的三个目标。
- **分类：** 将同类物品归在一起。临时堆放要范围小，且不要挡在过道上，以免在整理第一个烂摊子时又制造出第二个。
- **复查：** 离开前重新检查已完成的区域。十秒钟的检查能省下之后几分钟的折返。

新玩家容易忍不住抓起最近的电池就开始摆放。这感觉很有成效，但通常会让你的注意力分散到三四个半途而废的区域。先观察，后行动——这个顺序就是全部诀窍。

| 循环阶段 | 你做什么 | 防止什么 |
| --- | --- | --- |
| 扫描 | 在触碰任何东西之前完整勘察一个区域 | 抓起你看到的第一件物品 |
| 分类 | 将相似的电池归到一个小暂存点 | 难以检查的混合堆放 |
| 复查 | 离开前重新检查已完成的架子 | 放错位置的物品和已清空但未填满的槽位 |

还有一条值得尽早内化的规则：如果一层架子已经整理好了，就别碰它。重新整理干净的架子，是新手白白耗费一整场游戏却毫无可见进展的最常见方式。

## 设置你的第一条整理路线

路线就是固定的移动顺序。它应该从你一眼就能认出的地标开始——架子边缘、桌子、门口——然后沿一个方向穿过相连的储物区。每次游戏都重复同一条路线，导航就不再消耗你的注意力。

以下是适用于几乎所有地堡布局的首次游戏流程：

1. **选择一个起始地标。** 选择最显眼的架子或桌子，而不是多个物品组重叠的拥挤角落。
2. **移动前先勘察。** 用目光扫过整个区域。记下散落的电池、空余空间，以及明显属于别处的物品。
3. **建立一个临时分组。** 把你正在处理的电池放在一个明确的位置，足够近以便拿取，但要与已完成的储物区分开。
4. **完成当前架子。** 在继续前进之前，完成你已经开始的区域。一层完成的架子是一个你可以信赖的进度标记。
5. **复查并记录状态。** 再次检查架子，判断它是否完成，并在下次游戏时从最近未完成的区域开始。

| 路线阶段 | 行动 | 避免 |
| --- | --- | --- |
| 勘察 | 检查整个区域 | 立即拿起物品 |
| 分组 | 只保留一个临时堆放点 | 制造多个混合堆放点 |
| 摆放 | 完成选定的架子 | 留下一层整理到一半的架子 |
| 复查 | 重新检查已完成的区域 | 假设每件物品都放对了 |
| 过渡 | 移动到最近的未完成区域 | 在地堡里随意跳跃 |

路线不需要在第一天就完美。它们需要在你每次回来时都一模一样。社区中处理类似整理任务的玩家反馈一致提到，固定的起点比高效的起点更重要。

## 为规模化打造的电池整理系统

当长期目标涉及数百块电池时，分类必须简单到你在疲惫时也能使用。在初期，宽泛的分组胜过精细的分组；等基础操作变得自然而然后再增加细节。

使用四个工作分组：

- **未分类：** 当前扫描中发现的电池。保持这个分组小而临时。
- **准备摆放：** 你已经确认并即将储存的物品。
- **已完成：** 已经放置在选定架子上的电池。没有理由就不要动它们。
- **复查：** 任何类别或去向不明确的物品。在将区域标记为完成之前解决这些。

| 分组 | 目的 | 游戏规则 |
| --- | --- | --- |
| 未分类 | 新发现的电池 | 在切换区域前清空它 |
| 准备摆放 | 已确认等待槽位的物品 | 将其放在当前活跃架子旁边 |
| 已完成 | 已经整理好的电池 | 除非有问题，否则不要碰 |
| 复查 | 不确定或放错位置的物品 | 在标记区域完成前清空它 |

当你把一块不确定的电池混入已确认的堆放点时，那个堆放点就不再可信了。单独设置一个复查分组只多花一步，却能省下之后整轮重新分类。

玩家经验还建议在储物系统内部使用视觉地标——架子边缘、角落、特定的箱子——这样外观相似的房间就不会在你的记忆中混在一起。

## 追踪进度，避免重复区域

一旦每个区域都有状态，庞大的目标就变得可控。你不需要电子表格；三种状态就够了。

- **未开始：** 该区域从未进行过完整扫描。
- **进行中：** 物品已被移动，但架子仍需最终复查。
- **已完成：** 该区域已检查，且没有未解决的电池分组。

| 状态 | 含义 | 下次游戏做什么 |
| --- | --- | --- |
| 未开始 | 尚未完整扫描 | 先勘察该区域 |
| 进行中 | 分类已开始，复查未完成 | 完成同一个区域 |
| 已完成 | 已检查并整理好 | 移动到最近的未完成区域 |
| 需要复查 | 一件或多件物品仍不确定 | 解决复查分组 |

在停止游戏之前，执行这个简短清单：

- 选择了一个起始架子或储物区域
- 在移动任何东西之前勘察了区域
- 创建并清空了一个临时电池分组
- 选定的架子已完成并复查
- 区域已标记为未开始、进行中或已完成

短暂的游玩从来不是浪费进度。干净地完成一个区域，能减少之后争夺你注意力的区域数量，这正是让 420 块电池目标变得可达成而非令人望而生畏的原因。

## 区分顺畅游戏与混乱游戏的习惯

一旦路线变得自然，下一个改进不是移动得更快——而是减少浪费的移动。保持起点一致，在换房间之前完成当前分组，并且总是把不确定的物品放进复查分组，而不是靠猜。

| 习惯 | 新手收益 | 何时使用 |
| --- | --- | --- |
| 单区域游戏 | 进度容易衡量 | 每次游戏 |
| 临时复查分组 | 防止可疑的摆放 | 每当物品不明确时 |
| 固定起始地标 | 路线保持易记 | 每次回到地堡 |
| 游戏结束审计 | 减少重复搜寻 | 就在你停止之前 |
| 先宽泛分类 | 保持早期整理轻松 | 最初几次游戏 |

## Bunker Tidy Up 新手指南常见问题

**新手应该首先关注什么？**

一层可见的架子或一个储物区域。在移动任何东西之前勘察它，将找到的电池分组，完成该局部区域，并在扩大路线之前复查它。遵循这个顺序，是让本 Bunker Tidy Up 新手指南其余内容变得直观的最快方法。

**公开的整理目标涉及多少块电池？**

公开分享的游戏信息强调 420 块电池是一个主要的收集和整理目标。把它当作长期目标，并将其分解为一个个完成的区域，而不是试图一次性追完整个数字。

**我应该一次性整理所有物品类型吗？**

不。先从电池开始，使用宽泛的分组——未分类、准备摆放、已完成和复查。只有当基础系统已经能不加思索地运行时，才增加更细的分类。

**如何避免重复清理同一个区域？**

使用固定的起始地标，并将每个区域标记为未开始、进行中或已完成。每次游戏结束时快速复查，能准确告诉你下一次从哪里开始。

可靠的新手方法始终不变：先扫描，分类一个类别，完成一个区域，在继续前进之前复查。有了稳定的路线，杂乱的地堡会变成一个可读的空间，而庞大的电池数量也会变成一连串小而令人满足的胜利。
