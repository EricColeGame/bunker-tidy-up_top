两层楼间散落着超过 17,000 件零散物品，Bunker Tidy Up 与其说考验速度，不如说考验你是否知道东西该放哪儿。社区报告显示物品总数达 17,437 件，这意味着逐个记忆货架位置注定是一场打不赢的仗。不过，一旦你理解了 Bunker Tidy Up 补给品的分类体系，混乱就会变成可重复执行的日常流程。最快完成的玩家不是跑最多趟的人——而是从不把一摞东西搬到错误目的地的人。

整理 Bunker Tidy Up 补给品的核心思路很简单：每件物品都属于某个类别家族，而每个类别家族都有自己的归属地。学会五个家族，分批搬运，把繁琐的手动搜索留到最后。

## 为什么 Bunker Tidy Up 补给品要按分类整理，而不是按货架？

地堡在每次清理之间会重新布局，所以确切的货架位置并不可靠。保持不变的是分类逻辑。罐头食品和其他杂货放在一起，饮料有自己的区域，生存装备占据独立区域，卫生用品集中归置。这种规律在任何一次重新洗牌后都依然成立，因此识别分类是唯一值得反复练习的技能。

分类思维还能解决游戏中最浪费时间的问题：来回折返。每次穿越地堡的往返都会消耗真实的整理时间，而放错位置则要付出双倍代价。当你捡起一件不熟悉的物品时，先确定它属于哪个家族，再决定它该上哪个货架。

- **食品和饮料**——楼下的杂货区
- **生存补给品**——楼上的实用工具与应急储藏区
- **卫生与家居用品**——楼上的浴室和清洁用品货架
- **宠物护理**——楼上的宠物食品区
- **收藏品**——鸭子及类似特殊物品，留到最后处理

玩家经验表明，仅仅养成五大家族分类的习惯，就能消除大部分目的地混淆，甚至在你还没记住任何一个货架标签之前。

## Bunker Tidy Up 补给品地图：楼下 vs. 楼上

游戏中最实用的规则是两层楼划分：食品和饮料放在楼下，所有与生存、卫生或宠物相关的物品放在楼上。装有电池、火柴、药品和小工具的混合堆可以根据其分类标签归入任一方向，所以搬运前先确认。

| 目的地区域 | 常见物品组 | 整理优先级 |
| --- | --- | --- |
| 楼下 | 罐头食品、饮料、酱料、香料、饼干 | 高 |
| 楼上 | 生存物资、卫生用品、宠物食品、家居用品 | 高 |
| 混合堆 | 电池、火柴、药品、小工具 | 中 |
| 特殊物品 | 鸭子及其他收藏品 | 低，待主楼层清空后处理 |

把这张表当作整理地图，而非保证书。有些物品会被塞在家具后面、埋进密集堆里，或部分被其他物品遮住。如果某样东西看起来不见了，先扫视周围地面，再判断是不是目的地货架出了问题。

## 每件 Bunker Tidy Up 补给品该放在哪里

分类是大多数玩家浪费时间的地方，因为日常逻辑并不总是与游戏标签一致。蛋黄酱被归为酱料而非某种奇怪的调味品，能量饮料归入饮品，能量棒则被视为生存口粮。这些小的错位如果不学会，会导致无尽的重复跑腿。

| 物品类型 | 预期分类 | 实际目的地 |
| --- | --- | --- |
| 蛋黄酱 | 酱料 | 楼下酱料架 |
| 能量饮料 | 饮料 | 楼下饮料区 |
| 能量棒 | 生存 | 楼上生存区 |
| 罐装水果 | 罐头食品 | 楼下杂货区 |
| 猫粮 | 宠物食品 | 楼上宠物护理区 |
| 狗粮 | 宠物食品 | 楼上宠物护理区 |
| 洗发水 | 卫生 | 楼上卫生区 |
| 牙刷 | 卫生 | 楼上卫生区 |
| 电池 | 实用工具或生存 | 混合补给堆 |
| 火柴 | 实用工具或生存 | 混合补给堆 |

### 需要注意的分类例外

最棘手的物品是那些看起来像某样东西、实际却不是的物品。能量棒和能量饮料名称几乎相同，却放在完全不同的区域。蛋黄酱被归入酱料架，而不是跟杂货放在一起。每次放下整摞物品前都要确认货架分类——两秒钟的检查胜过一整趟往返。

一份临时记忆清单会很有帮助：

- **楼下食品：** 罐头餐食、水果、蔬菜、肉类、饼干、糖、花生酱、果酱、酱料
- **楼下饮料：** 果汁、汽水、啤酒、能量饮料
- **楼上生存：** 能量棒、药品、火柴、电池、收音机、手电筒
- **楼上卫生：** 牙刷、牙膏、洗发水、沐浴露、剃须刀、除臭剂
- **楼上宠物护理：** 猫粮、狗粮

来自一次共享清理会话的社区报告还提到了一些不寻常的数量：180 把牙刷、42 台收音机、30 支手电筒、50 枚破片手雷，以及仅有四个水桶。这些数字作为进度标记很有用，但不应被视为每个游戏版本固定的物品库存数据库。

## Bunker Tidy Up 补给品分步整理路线

随机乱扫会把两小时的清理变成六小时的苦差事。基于路线的整理方法能让地堡从头到尾保持清晰可读，即使堆放布局发生变化也能奏效。

1. **先清出主要通行区域。** 从桌子、椅子、主要货架周围和中央地面的物品开始。畅通的通道能改善视野，防止你走过被大堆物品挡住的东西。
2. **把楼下和楼上的物品分开。** 用分类地图把零散物品分成两大组，然后为每个目的地专门跑几趟。
3. **一次只针对一种物品类型。** 挑一件物品——电池、火柴、狗粮、罐装水果——使用物品搜索功能，收集一摞合理的数量，然后一起送回。
4. **对密集堆善用能力。** 磁铁式收集对电池、火柴、止痛药和绷带这类细小且数量多的物品最有价值。
5. **最后手动检查收尾。** 当只剩几百件物品时，停止依赖能力，手动走遍每个楼层区域。

| 清理阶段 | 推荐操作 | 为何有效 |
| --- | --- | --- |
| 开场扫荡 | 清空开阔地面区域 | 改善移动和视野 |
| 分类扫荡 | 分开搬运食品、饮料和补给品 | 减少目的地混淆 |
| 搜索扫荡 | 一次只针对一种物品类型 | 避免随机乱扫 |
| 密集堆扫荡 | 使用收集能力 | 节省处理小物品的时间 |
| 最终扫荡 | 手动检查 | 发现孤立或隐藏的物品 |

大堆物品值得特别对待。2026 年一条宣传帖的社区报告指出游戏中存在 420 块电池，这意味着一块一块地收集纯属浪费时间。分批搜出来，整摞送回，然后在切换分类前确认剩余数量。

**高效路线一句话总结：** 先清开阔地面，再分大类，然后处理大堆，最后收拾零散遗留。

## 能力、搜索与隐藏的 Bunker Tidy Up 补给品

后期清理需要的是耐心而非速度，因为还留在地面上的物品正是你已经走过两次的那些。在一次记录中，最后找不到的止痛药最终是在地毯下面被发现的，而不是在任何货架或桌子上。这就是全部的教训：一个房间看起来完成了，仍可能藏着一件物品。

| 问题 | 最佳应对 | 避免 |
| --- | --- | --- |
| 细小物品太多 | 分批搜索并收集 | 一块一块地捡电池 |
| 物品似乎不存在 | 检查家具下方和地毯边缘 | 假设它从未生成 |
| 目的地错误 | 重新核对分类标签 | 仅凭外观判断 |
| 最后一件物品未找到 | 缓慢而有条理地扫描地面 | 断定房间已空 |

三种能力工具各有不同作用。**物品搜索** 是主力——当你知道物品类型但在密集堆里找不到时就用它。**磁铁能力** 最好留给数量庞大的细小物品或被杂物挡住的东西。**货架寻找器** 在早期有帮助，但一旦你熟记分类布局后价值就会下降，所以在清理进行到一半时就别再依赖它们了。

一些习惯能让整套系统更可靠：

- 走遍每个堆之前先搜索
- 扫描时保持选中物品可见
- 检查你角色正下方的地面
- 检查地毯边缘、角落和家具底部
- 周围区域清空后重新检查密集堆
- 用完成计数确认某个分类确实已经完成

对于收藏鸭子，等到主要仓储分类都处理妥当再动手。社区报告指出鸭子的音效可能明显比其他游戏音效更响，所以在最后的找鸭子环节前调低整体音量会让过程舒适得多。

| 最终扫尾完成 | 家具或地毯下没有遗留孤立物品 |

**问：Bunker Tidy Up 补给品的主要目的地分组有哪些？**

楼下负责食品和饮料，楼上负责生存补给品、卫生用品、宠物食品和家居必需品。电池、火柴、收音机和药品通常来自混合实用工具堆。

**问：能量饮料和能量棒分别放在哪里？**

能量饮料属于楼下的饮料组。能量棒被归类为楼上的生存补给品。把这两者分开可以避免重复的分类错误。

**问：最快清空电池的方法是什么？**

使用物品搜索功能，按合理批量收集电池，当堆变得难以扫视时切换到磁铁式能力。鉴于电池组规模庞大，单件拾取永远不值得。

**问：当一件物品找不到时该怎么办？**

搜索地毯边缘、家具下方、角落和密集堆。最后一件物品往往是部分被遮挡，而不是明显摆在货架上。

核心策略始终不变：记住分类目的地，分批搬运，把详细的手动检查留到最后一遍扫尾。把地堡看作一条路线而非一大堆物品，17,000 件物品的清理就不再感觉不可能。
