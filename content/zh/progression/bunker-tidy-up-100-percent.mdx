地堡里的每个货架都有标签，每个类别都有自己的归宿，可地板上却不断堆满你确信早已收好的物资。这就是 **Bunker Tidy Up 100% 完成度** 的陷阱：游戏在第一个小时里显得平静、清晰，可一旦那些显眼的物品堆消失，它就变成大海捞针般的搜寻。完成一次全清并不靠反应速度——而在于优先升级正确的能力、按类别路线推进，并把最后一段当成一个独立项目来处理。把这三点做好，Bunker Tidy Up 100% 通关就会变成一场稳定、近乎冥想式的长期整理，而不是无尽往返的循环。

## Bunker Tidy Up 100% 完成度流程的四个阶段

游戏的宣传描述称地堡里大约有 17,437 件可分类物品，这立刻说明了这是什么样的项目：一款长线整理模拟游戏，而不是一个下午就能做完的快速任务。物品范围涵盖食物、饮料、家居用品、生存装备、医疗用品、书籍、武器等等。

根据玩家经验，进度大致遵循一条相当可预测的曲线。开局数小时进展很快，因为大型物体容易发现；当只剩外观相似的小物件时，一切都慢下来。了解自己处于哪个阶段，可以避免你在错误的时间使用错误的工具。

| 阶段 | 你实际在做的事 | 最佳方法 | 进度感受 |
| --- | --- | --- | --- |
| 开局 | 熟悉货架区域与标签 | 分拣轮廓明显的大家伙：桶、箱子、发电机、背包 | 快速且有成就感 |
| 扩张 | 搭建效率工具组 | 把点数花在携带与收集升级上 | 稳定 |
| 批量清理 | 清掉重复出现的物品种类 | 每趟批量处理一两个类别，对成组物品使用磁吸 | 由势头驱动 |
| 精细清理 | 搜寻隐藏的小物品 | 手动扫视加物品寻找器，一次一个类别 | 缓慢而有条理 |
| 核验 | 确认没有遗漏 | 走遍两层楼，检查角落和大型道具下方的空间 | 紧张但短暂 |

一个有用的心态重置：前半程你是收集者，后半程你是侦探。收集奖励宽广、贪婪的路线；侦探工作则奖励狭窄的专注，以及手中拿着一件参考物品。

## 升级优先级：先容量，后速度

升级是影响你完成时间的最大单一杠杆。早期点数应当减少你往返的次数；后期点数应当减少你花在搜寻上的时间。把这个顺序颠倒的玩家，最终走同样走廊的频率会翻倍。

在第一个小时里，携带容量和手持储物最重要，因为每一次返回货架都是纯粹的开销。一旦你能用一两次搬运就送完一个完整类别，磁吸和物品寻找工具就会立刻开始回本。

| 升级 | 优先级 | 最佳购买时机 | 真正节省的东西 |
| --- | --- | --- | --- |
| 拾取/携带容量 | 最高 | 最初几点 | 数十次往返货架 |
| 堆叠处理 | 高 | 前期到中期 | 整理相同副本所花的时间 |
| 移动速度 | 中 | 前期或中期 | 楼层间的长途行走 |
| 磁吸 | 高 | 中期 | 手动拾取散落物品组的时间 |
| 物品寻找器 | 高 | 中后期 | 数小时盲目搜寻稀有副本 |
| 终极存放 | 中高 | 后期 | 整理混合库存的时间 |

### 前期应跳过什么

不要把你最初的点数投入跳跃高度或外观性的移动加成。更快的移动无法弥补你带着几乎空空的库存、一瘸一拐地回到货架；而垂直移动也很少能解决真正的瓶颈——物品识别。把这些便利性购买留到容量、磁吸和寻找器都已解锁之后再考虑。

社区反馈也警告不要只过度升级某一个能力，而排斥其他能力。一套均衡的能力组合——中等容量、可用的磁吸、能正常工作的寻找器、可靠的终极存放——几乎总能胜过单一满级属性。

## 可重复的分拣路线，一步一步来

1. **空手走一圈。** 双手空空走遍两层楼，记下主要区域的位置：饮料、杂货、零食、香料和酱料、罐头食品、宠物食品、家居用品、生存装备、药品、书籍和武器。
2. **先清理大型物体。** 水桶、燃料罐、背包、发电机、灭火器和箱子都有不会认错的轮廓。它们能积累早期经验，并腾出地面空间。
3. **建立双类别路线。** 把货架彼此靠近的物品类型配对，这样一趟就能覆盖两个需求，而不是一个。
4. **经常存放，但别太频繁。** 在自然的休息点清空满库存，而不是每拿三件物品就折返。
5. **把能力用在成堆物品上，而不是剩货上。** 磁吸和终极存放用在二十件匹配物品的密集堆上，远比用在最后两三件零散物品上更有价值。
6. **切换到精细模式。** 当一个类别快完成时，手持一件该物品的副本，让寻找器引导你，而不是依赖记忆。

| 物品组 | 有用的视觉线索 | 处理提示 |
| --- | --- | --- |
| 饮料 | 瓶子、罐子、纸盒 | 货架靠近时与水的产品一起批量处理 |
| 罐头食品 | 统一的金属圆柱 | 成堆时容易发现，单独时容易被漏掉 |
| 宠物食品 | 袋子和罐头 | 把狗和猫的产品分开 |
| 书籍 | 扁平矩形和可见书脊 | 适合作为中期行程的填充物品 |
| 医疗用品 | 白色套装、绷带、泡罩包装 | 寻找器能力在这里最出彩 |
| 家居用品 | 清洁瓶、盒子、管子 | 仔细检查上层货架和角落 |
| 生存装备 | 背包、灭火器、工具 | 趁轮廓还明显时尽早清掉 |

## 后期清理：追查最后的隐藏物品

最后一段是大多数 Bunker Tidy Up 100% 尝试停滞的地方。大的类别已经完成，剩下的是数百个相似的小物件——罐子、广口瓶、电池、火柴、牙膏、食品包装——它们在视觉上融进了地板和货架。

解决办法是纪律，而不是速度。选一个剩余数量可控的类别，把它彻底完成，然后再继续。不断在物品类型之间切换会让你无法记住已经检查过什么，并保证你会重复搜索。

| 后期问题 | 实用解决方案 |
| --- | --- |
| 小物品在视觉上消失 | 按形状、颜色和货架类别搜索，而不是按名称 |
| 还剩一两个副本 | 手持一件匹配物品并触发寻找器 |
| 库存瞬间填满 | 更频繁地存放，并提高手持容量 |
| 能力感觉被浪费 | 把它们留给剩余副本密集的堆 |
| 某件物品放不到任何地方 | 先查看类别指示器再猜测 |
| 进度似乎卡住了 | 重新检查下层楼和之前清理过的路线 |

### 最终完成清单

- 走遍地堡两层楼和每个可到达的角落
- 手动完成低数量类别，而不是用能力
- 只在大量重复物品堆上使用磁吸
- 触发寻找器时，手里始终拿着一件物品
- 把终极存放用在满库存或混合库存上
- 确认没有任何货架类别还有未完成的堆叠

最后 10% 值得有自己的计划。那些带你走完流程中段的能力，到结尾往往会被浪费，所以慢下来，有条不紊地扫描，并把每个剩余类别当成一个小而独立的活儿。

## 会让 Bunker Tidy Up 100% 存档停滞不前的错误

| 错误 | 为什么有害 | 更好的习惯 |
| --- | --- | --- |
| 没有类别地乱逛 | 同样的房间被反复搜索 | 每趟只专注一两种物品类型 |
| 囤积升级点数 | 早期容量升级会在数小时里产生复利效应 | 尽早花，花在携带上 |
| 对三件物品使用终极存放 | 长冷却白白浪费 | 留给装满的混合库存 |
| 忽视下层楼 | 物品会藏在你很少走的地方 | 长途路线中交替楼层 |
| 相信记忆 | 数百件几乎一模一样的物体 | 手里留一件参考副本 |
| 猜测货架位置 | 放错物品会拖慢最终计数 | 每次都使用货架指示器 |

这些错误单独来看都不致命，但它们会叠加。两三个一起出现，很容易让原本节奏正常的流程多花一个小时。

## 常见问题

**Bunker Tidy Up 100% 完成度需要多长时间？**
大多数玩家应预留几个小时。一份广泛流传的通关参考大约在四个半小时内完成，但你的时间很大程度上取决于升级选择、你多快学会货架布局，以及你处理最终清理时多有方法。

**我应该先买哪个升级？**
携带容量。它是最安全的早期投资，因为它让每一趟都更有产出。接下来是堆叠处理，然后是磁吸，再然后是物品寻找，最后当你的库存能持续装满时，再买终极存放。

**一次只整理一个类别会更好吗？**
在流程后期，绝对如此。以类别为中心的整理让剩余数量容易追踪，并阻止你重新搜索已经清理过的房间。早期你可以更宽松一些，顺手抓取附近的大型物体。

**当只剩几件物品时，我该怎么做？**
手持一件缺失物品的副本，如果有寻找器能力就使用它。否则，手动且刻意地搜索地堡——角落、大型物体下方的空间、下层楼边缘，以及你走过几十次却从未仔细看过的货架。
