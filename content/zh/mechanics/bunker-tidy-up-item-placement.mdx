## 为什么地堡整理的物品摆放比速度更重要

两层楼里散落着超过 17,000 件物品，地堡整理的物品摆放决定了你是享受一次畅快的清理，还是花上几个小时来回折返。根据玩家经验，一局游戏里可能包含 420 块电池、180 支牙刷和几十台收音机，所以靠猜来摆放绝不是策略。好消息是，地堡整理的物品摆放遵循一条简单的分类逻辑：食物和饮料放楼下，而生存装备、卫生用品和宠物用品放楼上。

这一条规则就能消除大部分困惑。当你捡起一件不熟悉的物品时，只需要回答一个问题——这是楼下的物品还是楼上的物品？——然后决定去哪个货架。速度是之后的事，等分类变成本能、你不再对每一堆东西犹豫不决时自然就会快起来。

| 目的地区域 | 典型物品类别 | 整理优先级 |
| --- | --- | --- |
| 楼下食品储藏区 | 罐头食品、酱料、香料、饼干 | 高 |
| 楼下饮料区 | 果汁、汽水、啤酒、能量饮料 | 高 |
| 楼上生存区 | 电池、火柴、收音机、手电筒、药品 | 高 |
| 楼上卫生与宠物护理区 | 牙膏、洗发水、狗粮和猫粮 | 中 |
| 混合堆 | 小工具、零散消耗品、手雷 | 中 |
| 收藏品 | 鸭子和其他隐藏物品 | 低，等主楼层清完再说 |

这张表是一份整理地图，而不是对每一堆物品的保证。零散物品可能藏在家具后面、埋在密集的堆里，或者卡在拥挤的角落。社区反馈还表明，某些物品的确切数量会在不同存档之间变化，所以把这些数字当作进度标记，而不是固定的物品清单。

## 分类地图：楼下与楼上

把地堡想成两个目的地，而不是一大堆杂物。楼下的货架负责一切可食用或可饮用的东西。楼上的货架负责一切与生存、清洁或宠物护理相关的东西。一旦你把这种划分内化于心，你在拿起物品之前就能判断出大部分物品该往哪送。

### 楼下：食物、饮料和储藏物品

*   罐头食品、罐装水果、蔬菜和肉
*   果汁、汽水、啤酒和能量饮料
*   花生酱、果酱、糖和香料
*   蛋黄酱及类似酱料
*   饼干和干燥零食

### 楼上：生存、卫生、宠物护理和家用物资

*   能量棒、药品、止痛药和绷带
*   电池、火柴、收音机和手电筒
*   洗发水、沐浴露、剃须刀和除臭剂
*   牙刷和牙膏
*   猫粮和狗粮
*   清洁用品和一般家庭必需品

| 物品 | 类别 | 实际目的地 |
| --- | --- | --- |
| 罐装水果 | 罐头食品 | 楼下食品杂货货架 |
| 蛋黄酱 | 酱料 | 楼下酱料货架 |
| 能量饮料 | 饮料 | 楼下饮料区 |
| 能量棒 | 生存用品 | 楼上生存区 |
| 电池 | 工具或生存用品 | 楼上混合物资货架 |
| 火柴 | 工具或生存用品 | 楼上混合物资货架 |
| 猫粮或狗粮 | 宠物食品 | 楼上宠物护理区 |
| 洗发水或沐浴露 | 卫生用品 | 楼上卫生区 |
| 牙刷或牙膏 | 卫生用品 | 楼上卫生区 |
| 收音机或手电筒 | 生存用品 | 楼上生存区 |

最稳妥的习惯是记住类别族群，而不是具体的货架坐标。每次清理时货架的布局可能略有不同，但罐头食品永远属于食品杂货，饮料永远有自己的区域，卫生用品总是归在一起。

## 容易混淆的物品与分类例外

有少数物品会打破“看起来像什么就放哪里”的直觉。蛋黄酱就是经典例子：大多数玩家在脑子里把它归为调味品，但游戏把它当作酱料，要求放在酱料货架上。能量饮料和能量棒则朝相反方向拆分——饮料放楼下的饮品区，而能量棒算作生存物品，属于楼上。

这些例外之所以重要，是因为一次放错就意味着白跑一趟穿过整个地堡。在放下物品堆之前先确认货架类别，如果物品放不下，就重新检查标签，而不是硬塞进看起来相似的货架。

| 常见错误 | 会发生什么 | 如何修正 |
| --- | --- | --- |
| 把蛋黄酱当调味品 | 物品堆无法在错误的货架上登记 | 把它当酱料，放楼下 |
| 把能量棒和饮料放一起 | 能量棒一直散落，弄乱饮料区 | 移到楼上生存区 |
| 一块一块地捡电池 | 楼上楼下跑上几百趟 | 用搜索或磁铁能力批量收集 |
| 跳过宠物食品 | 残余物品一直留在楼上 | 尽早把所有猫粮狗粮送上楼 |
| 只凭外观判断 | 反复放错货架 | 先确认类别族群 |

社区通关记录中的数量值得作为检查点了解。有报告提到大约 180 支牙刷、42 台收音机、30 支手电筒，以及数量少得出奇的水桶，这意味着有些类别很快就能清完，而另一些则拖得很久。不要假设这些数字适用于游戏的每个版本。

## 地堡整理物品摆放的分步路线

随机乱找是整个游戏里最大的时间黑洞。固定的路线能让楼层保持清晰可读，避免你三次路过同一件物品。这套顺序之所以有效，是因为它先清理视野，再减少判断，最后处理杂乱的剩余部分。

1.  **清空主要行走通道。** 捡起桌子、椅子、主要货架周围以及中央地面的一切物品。开阔的地面能让后续搜索更快，并降低漏掉藏在大堆物品后面东西的概率。
2.  **把零散物品分成两大类。** 先处理楼下物品——食物、饮料、酱料、香料。然后用专门的行程处理楼上物品：生存物资、卫生用品、家用物资和宠物食品。
3.  **一次只针对一种物品类型。** 选择电池、火柴、狗粮或罐装水果，使用搜索功能显示所有匹配项，收集合理的一堆，然后一趟送完。
4.  **对密集的物品堆使用收集能力。** 磁铁类能力在细小或数量众多的物品上最有用，比如电池、火柴、止痛药和绷带，这些东西在视觉上很难分辨。
5.  **以手动检查收尾。** 当只剩几百件物品时，别再依赖能力，慢慢走遍每个区域。这样才能找出藏在家具下或压在拥挤物品堆里的东西。

| 清理阶段 | 建议操作 | 为什么有效 |
| --- | --- | --- |
| 开场遍历 | 清空开阔地面区域 | 改善视野和移动 |
| 分类遍历 | 分开搬运食物、饮料和物资 | 减少目的地混淆 |
| 搜索遍历 | 针对单一物品类型 | 避免随机乱找 |
| 密集堆遍历 | 使用收集能力 | 节省小物品的处理时间 |
| 最后遍历 | 手动检查 | 找出孤立或隐藏的物品 |

## 搜索能力、密集物品堆和隐藏物品

游戏后期的清理与其说是体力活，不如说是耐心活。社区报告描述过，最后一片找不到的止痛药出现在地毯下面，而不是任何货架上，这就是为什么看起来已经清完的楼层仍可能藏着一件顽固的物品。把搜索和磁铁能力留给你知道物品类型、但在一片厚厚物品堆里找不到它的时候。

| 问题 | 最佳应对 | 避免 |
| --- | --- | --- |
| 细小物品太多 | 搜索并批量收集 | 一块一块地捡电池 |
| 物品似乎丢了 | 检查家具下方和地毯边缘 | 认定是货架不对 |
| 目的地错误 | 重新检查类别族群 | 只凭外观判断 |
| 还剩一件物品 | 缓慢而有条理地扫遍地面 | 宣布房间已空 |

几个习惯能让搜索系统更可靠：

*   在走遍每一堆之前先搜索。
*   扫描时让选中的物品保持可见。
*   检查角色正下方的地面。
*   检查地毯边缘、角落和家具底面。
*   周围区域清空后，再回头检查密集物品堆。

可收集的鸭子可以等到主要存储类别都整理好之后再说。它们的音效提示比其他游戏音效明显更响，所以在搜寻最后几只之前调低音量是合理的舒适性调整。想了解大型整理类游戏通常如何呈现和更新，可以参考 [Steam 的模拟游戏目录](https://store.steampowered.com/tags/en/Simulation/)。

| 完成度检查 | 需要确认的内容 |
| --- | --- |
| 食物完成 | 罐头食品、水果、蔬菜、肉和酱料都已放好 |
| 饮料完成 | 果汁、汽水、啤酒和能量饮料都已清空 |
| 生存用品完成 | 电池、火柴、收音机、手电筒和能量棒都已收纳 |
| 卫生用品完成 | 牙刷、牙膏、洗发水、沐浴露、剃须刀、除臭剂都已放好 |
| 最后扫尾完成 | 家具或地毯下不再有孤立物品 |

## 地堡整理物品摆放常见问题

**学习地堡整理物品摆放最快的方法是什么？**

先学会两层划分：食物和饮料放楼下，生存物资、卫生用品和宠物食品放楼上。在此基础上记住类别族群，而不是确切的货架位置，并在放下物品堆之前确认货架标签。这个方法能避免地堡里的大部分来回折返。

**能量饮料和能量棒分别放哪里？**

能量饮料和楼下饮品归在一起，而能量棒算作生存物资，属于楼上。尽早把这两类物品分开，能避免游戏中最常见的整理错误之一。

**处理 420 块电池最高效的方法是什么？**

不要一块一块地捡。使用物品搜索功能显示每一块电池，收集合理的一堆，然后一起送回去。当物品堆密集到肉眼难以分辨时，磁铁类能力会很有帮助。

**如果还剩一件物品找不到该怎么办？**

先检查低可见度的表面：地毯边缘、角落、家具底面和拥挤的物品堆。玩家经验反复表明，最后一件物品往往是部分被遮挡，而不是明晃晃地摆在货架上。

把地堡当成一条路线，而不是一大堆杂物。一次完成一个类别族群，分批作业，把细致的手动检查留到最后扫尾——这是让地堡整理的物品摆放变得轻松而不是无休无止的最可靠方法。
