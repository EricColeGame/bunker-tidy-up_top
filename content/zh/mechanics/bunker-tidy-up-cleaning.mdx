数千件散落的物资、100 多种物品类型，还有只接受特定类别的货架——这就是每座地堡中等待你的挑战。Bunker Tidy Up 清洁看似只是简单的杂活，但它奖励的是规划，而非快速点击。一旦顺序搞错，Bunker Tidy Up 清洁就会变成一个循环：白跑一趟、浪费冷却时间，还有那些藏在杂物后面、你永远不会注意到的小物件。主推地堡所宣传的物品数量——根据开发者的宣传资料为 17,437 件——直白地说明了这一点：面对那么大的房间，没有路线规划，再疯狂地点击也撑不下去。

## 为什么路线规划胜过单纯的手速

大多数玩家一开始都是抓离自己最近的东西。这种本能会造成最糟糕的模式：你面前的堆被清空了，但它后面的一切仍然堵着，而你也始终没能建立起每个类别存放位置的脑内地图。来自大型整理场景的社区反馈都指向同一个解决办法——先打通通道，再整理。

在房间中央与货架墙之间打通一条清晰的行走路径，比早早整理完一个类别更有价值。这条路径让你看清混乱的真实形状、发现类别之间的分界，并无需翻越箱子就能到达远处的储物区。让后期阶段变快的是视野，而不是速度。

| 清洁要素 | 实际作用 | 建议做法 |
| --- | --- | --- |
| 地面杂物 | 可见混乱的主要来源 | 在整理任何东西前先清出宽阔通道 |
| 储物货架 | 每件物品的最终归宿 | 尽早熟悉各类别的摆放位置 |
| 清洁技能 | 更快搬运同类物品 | 留到密集、明显的物品堆再使用 |
| 隐藏收集品 | 可选搜寻目标 | 等地面开阔后再去扫荡 |
| 收尾物品 | 容易漏掉的小物件 | 改用人工检查 |

开局原则很简单：当大堆物品仍然挡住你对房间的视野时，绝不要去追一件孤立的物品。先清空一大片区域，再利用那片开阔的地面来做规划。

## 行之有效的五阶段清洁顺序

地堡的储物区被划分为几个容易辨认的组别——书籍、生存物资、武器与防护、宠物食品、家用化学品、日用品和食物。即使开局时地面看起来一片狼藉，这些分组也应当指引你的路线。

大件物品和密集的堆是合适的早期目标，因为搬走它们能改善视野。中央地面变干净后，电池、火柴、洗漱用品、罐头、药品和单件工具等较小的物品终于能够被认出来。

| 阶段 | 主要目标 | 典型目标 |
| --- | --- | --- |
| 第 1 阶段 | 打通移动通道 | 大件地面堆、明显的容器 |
| 第 2 阶段 | 建立类别分区 | 书籍、食物、生存物资、卫生用品 |
| 第 3 阶段 | 归并同类物品 | 罐头食品、宠物食品、药品、电池 |
| 第 4 阶段 | 检查边角 | 椅子、角落、桌子、货架缝隙、地毯边缘 |
| 第 5 阶段 | 最终扫尾 | 单件物品、隐藏收集品、被埋住的物品 |

**1. 选定房间的一条边。** 从外墙或一个空旷的角落开始。沿着边缘作业能避免你反复穿过同样杂乱的中心区域，并为接下来的整轮清洁提供一个固定的参考点。

**2. 开辟一条中央路线。** 只需搬走足够形成一条连接主地面与货架的行走路径即可。一条可用的路线能改善通往后续每一组物品的通道，这也是它胜过立刻整理完一个类别的原因。

**3. 按目的地分组。** 只拿取属于同一货架区域的物品。食物、药品、书籍、宠物用品、卫生用品和生存物资应当分轮处理，而不是混在一起搬运。

**4. 在密集堆上使用技能。** 很多物品乍看之下几乎一模一样，所以在使用大规模自动拾取前先确认目的地。把混装的一堆搬运穿过房间，只会制造出额外的往返。

**5. 收尾时放慢节奏。** 当只剩下几百件物品时，密度优势便不复存在，手动整理反而更可靠。

## 技能、移动与库存管理

清洁技能是这个场景中的主要效率工具。有些能力可以收集同类物品，另一些则能提升携带容量、移动速度、货架交互或物品可见度。它们的价值在一轮清洁中会不断变化：在地堡塞满物品时不可或缺的能力，等到只剩寥寥几件物品时可能就成了累赘。

当大量相同物品集中在一处时，大容量拾取最为强力。面对独特物品、隐藏物品或分散在不同房间的物资时，它就弱得多。最高效的做法是在技能使用与手动整理之间交替进行，而不是在整轮清洁中死守其中一种方式。

| 技能或工具类型 | 最佳用途 | 不适用场景 |
| --- | --- | --- |
| 同类拾取 | 密集的相同物品堆 | 含相似物品的混合堆 |
| 提升携带容量 | 通往远处货架的长路线 | 目的地就在附近的短途往返 |
| 加快移动 | 在储物区之间往返 | 整理已经在货架旁的物品 |
| 货架匹配 | 熟悉不熟悉的目的地 | 类别已知的后期清洁 |
| 手动拾取 | 收尾物品和孤立物品 | 从一开始就清理整个房间 |

**大堆策略**

- 收集肉眼可见的同类物品堆。
- 确认类别后再激活同类匹配技能。
- 在切换目标前先把这一趟卸下。

**小堆策略**

- 手动拾取孤立的物品。
- 顺手检查附近的角落和家具。
- 避免为一件物品消耗漫长的冷却时间。

**最终扫尾策略**

- 关闭不再需要的辅助技能。
- 检查地面边缘、地毯边沿和货架缝隙。
- 利用货架清单确认还缺少哪种物品。

## 类别指南与隐藏物品搜寻

物资清单刻意设计得丰富多样，有几个类别很容易混淆。饮料可能与生存物资分开存放，而家用产品可能出乎意料地紧挨着食物或药品。请借助货架标签和物品轮廓来判断，而不要只依赖颜色——很多包装用的是同一套配色。

| 类别 | 示例 | 搜寻线索 |
| --- | --- | --- |
| 食物 | 罐头肉、水果、蔬菜、汤、果酱 | 检查下层货架和密集的食物堆 |
| 饮料 | 汽水、果汁、能量饮料、啤酒 | 独立的饮料区很容易被忽略 |
| 生存物资 | 能量棒、火柴、电池、收音机 | 常与小件实用物品混在一起 |
| 卫生用品 | 洗发水、牙膏、肥皂、剃须刀、牙刷 | 小物件常常遗留在边缘附近 |
| 药品 | 止痛药、绷带、碘酒、急救包 | 检查角落和已部分清理的堆 |
| 宠物用品 | 猫粮和狗粮 | 留意上层货架上反复出现的成堆物品 |
| 阅读材料 | 书籍和杂志 | 通常集中在一个独立的货架区 |

隐藏的橡皮鸭是另一个主要目标。它们可能被埋在堆里、塞在家具旁边，或者放在鲜艳颜色与周围杂物融为一体的地方。社区反馈建议在主地面开阔*之后*再去搜寻它们，然后重访仍含有说不清是什么物品的密集区域。

这个顺序很重要。一开始就去搜寻收集品，意味着要把物品堆翻两遍——一遍是为了找到鸭子，另一遍才是真正清理它周围的物资。

## 完成清单与最终扫尾

完成清洁不只是让中央区域看起来整洁。小物件可能仍藏在视觉杂物之下、家具旁边，或者沿着地毯边缘。最终检查应当综合物品计数器、货架状态、类别匹配，以及对房间的一次缓慢目视巡视。

| 完成检查项 | 需确认内容 |
| --- | --- |
| 物品计数器 | 没有未收集的物品残留 |
| 货架状态 | 每个储物区都能接收其对应类别 |
| 地面检查 | 家具附近没有藏着的孤立物品 |
| 收集品 | 所有隐藏橡皮鸭都已找到 |
| 房间边界 | 门和出口都已检查过 |
| 技能状态 | 剩余升级已使用或有意保留 |

**最终扫尾，按顺序进行：**

- 清理主要行走路线和房间边缘。
- 整理所有可见的食物和生存物资组。
- 检查药品、卫生用品和宠物用品货架。
- 搜寻角落、家具和地毯边沿，找出漏网之物。
- 离开前找出所有隐藏的鸭子。

利用类别筛选或匹配指示器确认还剩下什么，然后检查该物品类型最后一次出现的位置。这比随机扫视整个地堡要快得多。储物区整理完毕后，也检查一下房间边界和出口区域是否存在清洁后的互动——但要查看实际的互动提示，而不是想当然地认为每一扇看得见的门都通往新地方。

## 常见问题

**Bunker Tidy Up 清洁的主要目标是什么？**

目标是把散落的物资分类归入正确的储物区。这里没有战斗，也没有角色成长——真正的挑战是组织整理、路线规划，以及找出埋在大堆物品下的小物件。

**主地堡场景中有多少件物品？**

根据游戏的宣传信息，主推地堡包含 17,437 件物品。你的实际完成时间很大程度上取决于你使用技能的频率，以及你检查房间边缘的彻底程度。

**我应该一开局就激活清洁技能吗？**

当能看到一大群同类物品且其目的地明确时再使用它们。为后期密集的堆保留一些余量，但一旦只剩孤立物品就改用手动拾取，因为把冷却浪费在单件物品上很不划算。

**我应该去哪里找隐藏的橡皮鸭？**

搜寻密集的堆、角落、家具边缘，以及地面清理前难以检查的位置。在 Bunker Tidy Up 清洁过程中进行一次缓慢的最终扫尾，远比一开始就胡乱搜寻可靠得多。

清晰的路线、明确的类别分组，以及一次刻意的最终巡视，永远胜过一味求快。把地堡视为一连串区域，而不是一个巨大的堆，物品计数器的下降速度会比你想象的更快。
